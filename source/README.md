# 留白 · 个人博客

极简文艺风格的中文版个人博客。包含首页、4 篇完整示例文章、关于我及 404 页面；无登录、评论或后台发布系统，不收集访客资料。

## 本地运行

需要 Node.js 22.13 或更高版本。

```text
npm ci
npm run dev
```

运行 `npm run build` 生成静态站点，公共输出位于 `dist/client`。网站已配置静态导出，不需要数据库。

## 替换内容

- `lib/posts.ts`：文章标题、日期、摘要与正文。
- `app/page.tsx`：首页介绍、精选文章和列表摘要；新增文章时同步更新首页链接。
- `app/about/page.tsx`：关于我。
- `app/layout.tsx`：博客名称、页脚及网站描述。
- `app/globals.css`：颜色、字体及响应式排版。
- `public/coast.png`：本项目生成的海岸配图。不要当作真实作者拍摄作品。

当前文章和作者介绍均为示例，不代表使用者的真实经历。发布真实内容时请替换相应示例标识。
